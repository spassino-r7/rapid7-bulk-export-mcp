# Customer Notes — Usage Guide

Each file in this folder is a per-customer steering file with `inclusion: manual`.

## How to use in Kiro chat

Type `#` in the chat input and select the customer file you want to load into context.
Kiro will then have full awareness of that customer's environment, contacts, and current status for the conversation.

## File naming

Use kebab-case: `customer-name.md`
Examples: `acme-corp.md`, `contoso-ltd.md`

## Template

Copy `_template.md` to create a new customer file.
